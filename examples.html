Small, practical patterns you can adapt to your own server. Each example is based on the actual Novora v1.0.0 API.

01 · STARTER

Minimal JavaScript server

JavaScript
server.js
import { Novora } from "novora";

const app = new Novora({ logger: true });

app.get("/", async () => ({
    name: "Novora",
    status: "running"
}));

app.get("/hello/:name", async request => ({
    message: `Hello, ${request.params.name}!`
}));

app.health();

await app.listen(3000);
02 · REQUEST VALIDATION

Validate a JSON body

TypeScript
users.ts
import { Novora, z, validate } from "novora";

const app = new Novora();

app.route({
    method: "POST",
    url: "/users",
    preHandler: validate({
        body: z.object({
            name: z.string().min(1),
            email: z.string().email()
        })
    }),
    handler: async request => ({
        created: true,
        user: request.body
    })
});

await app.listen(3000);

The validation helper checks the request body before the route handler runs. It can also validate params, query and headers.

03 · ROUTING

Organize routes with a prefix

Router
routes.ts
import { Novora, Router } from "novora";

const app = new Novora();
const api = new Router("/api/v1");

api.get("/status", async () => ({ status: "ok" }));
api.get("/products/:id", async request => ({
    id: request.params.id
}));

app.mount(api);

app.group("/admin", router => {
    router.get("/dashboard", async () => ({
        page: "admin-dashboard"
    }));
});

await app.listen(3000);
04 · CACHE

Cache a computed value

TTLCache
cache.ts
import { TTLCache } from "novora";

const cache = new TTLCache({
    defaultTtl: 30_000,
    maxEntries: 500
});

const getGreeting = () => cache.getOrSet(
    "greeting",
    () => ({ message: "Hello from the cache!" }),
    10_000
);

cache.set("version", "1.0.0");
const greeting = getGreeting();

console.log(greeting);
console.log(cache.size);
05 · CONFIGURATION

Parse environment settings

Zod + dotenv
config.ts
import { loadConfig, z } from "novora";

const config = loadConfig({
    path: ".env",
    schema: z.object({
        PORT: z.coerce.number().default(3000),
        NODE_ENV: z.enum([
            "development",
            "production",
            "test"
        ]).default("development")
    })
});

console.log(config.PORT);
06 · ERROR HANDLING

Return structured HTTP errors

Errors
errors.ts
import { Novora, notFound, createError } from "novora";

const app = new Novora();

app.get("/users/:id", async request => {
    const user = null;

    if (!user) {
        throw notFound("User does not exist");
    }

    return user;
});

app.get("/demo", async () => {
    throw createError(422, "Invalid data", "INVALID_DATA");
});

app.setErrorHandler((error, request, reply) => {
    return reply.code(500).send({
        error: "INTERNAL_ERROR",
        message: error.message
    });
});

await app.listen(3000);

Novora serializes NovoraError instances and HTTP errors with status codes from 400 through 599 through its wrapper.
